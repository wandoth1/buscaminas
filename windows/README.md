# 🪟 Buscaminas v2 para Windows

Ejecutable nativo para Windows (compatible con Windows 10, 11 y versiones x86_64).

## 🚀 Cómo jugar
- Haz doble clic en **`Buscaminas_v2.exe`**.
- No requiere instalar dependencias, ni Python ni Rust.
- Aplicación nativa con aceleración gráfica por GPU a 60+ FPS y audio procedural en memoria.

## 🛠️ Recompilar
Si tienes el compilador de Rust instalado y deseas recompilar:
```bash
cargo build --release
```
O simplemente haz doble clic en `compilar_v2.bat`.
